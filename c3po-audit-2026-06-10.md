### CHECK 2 — Missing seoLocationName
**510 locations affected** — auto-fixable via snapshot

**Problem:** `seoLocationName` is NULL → live-data route uses street address as keyword instead of business name

**Why this matters:** SEO heatmaps use `seoLocationName` for keyword tracking. Missing = incorrect heatmap data.

**Recommended action:**
Set `seoLocationName` to `liveDataSnapshot.title` (business name) for all 510 locations.

**Auto-fix query:**
```sql
UPDATE "GBPLocation"
SET "seoLocationName" = "liveDataSnapshot"->>'title'
WHERE "seoLocationName" IS NULL
  AND "liveDataSnapshot"->>'title' IS NOT NULL;
```
